## Techstack 
* React.js
* Vite
* Tailwind CSS

## How to install and run this project
Make sure you have [Node.js](https://nodejs.org/) installed.

1. Clone this repository
2. Install dependencies: 
`npm install`
3. Start the development server: 
`npm run dev`
